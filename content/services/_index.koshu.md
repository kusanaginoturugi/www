## 開発を請ける仕事

話を整理するところから、設計、実装、運用までまとめてやるじゃん。

- 業務システムと社内ツール
- Web アプリと API
- データ集計と自動化のスクリプト
- 今あるシステムの直しや機能追加

Ruby on Rails、Hugo、シェルでの自動化なんかをよく使うよ。

## 技術の相談

「どっから手をつけりゃいいだ」ところから、一緒に整理するじゃん。

- 技術選びと設計の相談
- AWS、Cloudflare への移行の段取り
- コードレビューと直し方の提案
- 開発の進め方をよくする相談

## 運用と保守

- 監視とログの土台づくり

- セキュリティとバックアップの定期確認
